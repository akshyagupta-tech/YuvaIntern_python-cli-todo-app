# Advanced CLI To-Do List Application

A modular, feature-rich command-line task manager built using Object-Oriented Python.

## Advanced Features
- **Metadata Tagging:** Priority levels (High/Medium/Low), Categories (Work/Study/Personal), and optional Due Dates.
- **Search & Filter:** Keyword-based task querying and status-based filtering (Pending vs Completed).
- **ANSI Visuals:** Color-coded terminal display with formatted tables.
- **Persistent Storage:** Seamless JSON state management.
- **Defensive Error Handling:** Input sanitation and graceful KeyboardInterrupt handling.

## Installation & Setup
- Requires Python 3.8+ (Zero third-party package dependencies).

## How to Run
```bash
python3 todo_app.py
```
